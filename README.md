#  Vozes da Periferia

> Plataforma web desenvolvida como projeto acadêmico, voltada para Organizações Não Governamentais (ONGs), com foco em gestão de projetos sociais, captação de recursos e engajamento de voluntários.

---

##  Sobre o Projeto

**Vozes da Periferia** é uma plataforma que oferece presença digital profissional a ONGs, permitindo divulgar projetos, gerenciar voluntários, captar recursos e manter a transparência das ações.  
O sistema foi desenvolvido ao longo das quatro entregas do curso, aplicando os conhecimentos de **HTML5**, **CSS3**, **JavaScript**, **acessibilidade (WCAG 2.1)** e **Git/GitHub (GitFlow)**.

---

##  Objetivo Geral

Desenvolver uma aplicação web completa e responsiva que simula o ambiente digital de uma ONG real, aplicando de forma prática os conceitos estudados nas quatro unidades da disciplina.

---

##  Tecnologias Utilizadas

- **HTML5** — Estrutura semântica das páginas  
- **CSS3 (Flexbox & Grid)** — Estilização e responsividade  
- **JavaScript (DOM & SPA)** — Interatividade e funcionalidades dinâmicas  
- **Git / GitHub** — Controle de versão e deploy  
- **WCAG 2.1 AA** — Padrões de acessibilidade  
- **Google Fonts / Variáveis CSS** — Sistema de design e tipografia

##  Funcionalidades Implementadas

- Página inicial com informações institucionais e contato  
- Listagem de projetos sociais com galeria de imagens  
- Sistema de cadastro de voluntários com validação de formulários  
- Estrutura de **Single Page Application (SPA)** com JavaScript  
- Sistema de design com **paleta de cores e variáveis CSS**  
- Responsividade completa (mobile, tablet e desktop)  
- Acessibilidade: navegação por teclado, contraste e leitores de tela  

---

##  Acessibilidade (WCAG 2.1 - Nível AA)

O projeto foi desenvolvido com base nas diretrizes da WCAG 2.1:
- Navegação completa por teclado  
- Contraste mínimo de 4.5:1  
- Estrutura semântica adequada (uso de `<header>`, `<main>`, `<nav>`, `<footer>`)  
- Suporte para leitores de tela  
- Modo de alto contraste e dark mode acessível  

---

##  GitFlow e Versionamento

O fluxo de versionamento foi feito utilizando o padrão **GitFlow**, com as seguintes branches:

- `main` → versão estável em produção  
- `develop` → ambiente de desenvolvimento  
- `feature/*` → novas funcionalidades  
- `release/*` → preparação de releases  

A versão final foi marcada com o **tag semântico**:


v1.0.0
